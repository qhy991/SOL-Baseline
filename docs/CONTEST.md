Baselines for the Contest evaluation set under `data/benchmark/Contest/`. Targets DeepSeek-V3 / Qwen3-VL / Kimi-K2 / Gemma-3 / Nemotron / gpt-oss patterns — FP8 blockwise, MLA, large-scale MoE, and ultralong attention.

### High-value patterns established

**FP8 blockwise (1×128 act / 128×128 weight) GEMM** — the DeepSeek/Qwen FP8 recipe:

```python
import flashinfer.gemm as fg
out = fg.gemm_fp8_nt_groupwise(
    qx, qw, sx, sw,                            # qx, qw fp8_e4m3; sx, sw float32
    scale_granularity_mnk=(1, 128, 128),
    scale_major_mode='MN',
    out_dtype=torch.bfloat16,
)
```

With `scale_major_mode='MN'`, scale shapes are:
- `sx`: `(K // 128, M)` — transpose of `(M, K//128)` that `compute_scales` naturally produces
- `sw`: `(K // 128, N // 128)` — transpose of `(N//128, K//128)` blockwise weight scaling

Both must be `.t().contiguous()`.

Covered tasks: Quant/002, 003, 004, 005, 011, 012, 013, 015, 016.
